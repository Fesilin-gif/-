# PROJECT AMB — сайт студии декораций

Одностраничный сайт студии, которая создаёт, изготавливает и монтирует декорации
для свадеб, детских праздников, шоу, корпоративных и частных мероприятий,
плюс отдельные страницы проектов.

Next.js 15 (App Router) · React 19 · TypeScript · GSAP + ScrollTrigger · Lenis.

## Запуск

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # продакшн-сборка
npm start        # запуск собранного
npm run lint     # tsc --noEmit
```

## Структура

```
app/
  layout.tsx            шрифты, метаданные, шапка/подвал, motion-слой
  page.tsx              порядок секций главной
  globals.css           дизайн-система: токены, типографика, примитивы
  sections.css          композиция каждой секции
  projects/[id]/        страница проекта (SSG по списку из lib/content.ts)
  api/lead/route.ts     приём заявки
components/             секции и общие элементы
lib/content.ts          весь текст и контакты — единственный источник
lib/media.ts            реестр фотослотов
public/media/           изображения
scripts/generate-media.mjs  генератор плашек-заглушек
```

## Фотографии

Внешние фотостоки недоступны из сборочного окружения, поэтому в слотах лежат
художественные плашки, сгенерированные `scripts/generate-media.mjs`: мягкие
сцены в палитре проекта — арка с флористикой, драпировка, подвесные кольца,
сервировка, сценический свет. Они держат композицию и тон, но настоящие
фотографии заменят их напрямую.

Как поставить свои фотографии:

1. Положите файлы в `public/media/`.
2. В `lib/media.ts` поправьте у нужного слота `src`, `alt`, `width`, `height`
   и при необходимости `focus` (точка кадрирования для сильно обрезанных слотов).
3. Больше **не запускайте** `scripts/generate-media.mjs` — он перезапишет
   файлы с теми же именами.

Слоты: `hero`, `weddings`, `kids`, `show`, `project-01…05`, `statement`,
`approach`, `team-01…04`.

Портреты команды намеренно без лиц: в карточках указаны роли, а не выдуманные
имена. Поставьте настоящие фотографии — и раздел будет готов.

## Дизайн-система

| Слой | Значение |
| --- | --- |
| Фон | `#F5F1EA` / `#F1EDE6` / `#ECE7DF` + зерно |
| Текст | `#171714`, `#23221F`, приглушённый `#5F5D56` |
| Акцент | `#B69A78` / `#C3A98A` — только линии, номера, метки |
| Тёмный блок | `#1A1917` (глава «Шоу», разворот-цитата, подвал) |
| Антиква | Cormorant Garamond 300/400 — заголовки и крупные фразы |
| Гротеск | Onest 300/400/500 — интерфейс, навигация, мелкий текст |
| Радиусы | 24–32px, только на ключевых плоскостях |

Акцентный бежевый используется только декоративно — контраста с бумагой ему
не хватает для текста, поэтому весь читаемый текст идёт чернилами.

Сетка: на телефоне блоки просто идут друг за другом, 12 колонок включаются
с 900px. Мобильная версия — отдельная композиция, а не уменьшенный десктоп.

## Анимации

Три приёма, все медленные, все на `transform` и `opacity`:

- появление блоков при скролле — `opacity` + `translateY(24px)`, стагер 70ms,
  1.05s, `power3.out`, срабатывает один раз;
- вход первого экрана — одна оркестрованная сцена: кадр раскрывается
  `clip-path`, изображение уходит со `scale(1.08)` в `1`, текст выходит стагером;
- лёгкий параллакс крупных кадров (±5%) и медленный `scale` при наведении.

Плавный скролл — Lenis, он же ведёт якорные ссылки.

При `prefers-reduced-motion: reduce` не запускается ничего: синхронный скрипт в
`<head>` не ставит класс `.js`, стартовые состояния не применяются, контент
статичен. Без JavaScript сайт тоже полностью читается.
