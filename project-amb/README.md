# PROJECT AMB

Сайт студии декораций PROJECT AMB: свадьбы, детские праздники, шоу и
корпоративные мероприятия.

## Запуск

```bash
npm install
npm run dev      # http://localhost:3000
npm run build && npm start
npm run lint     # проверка типов
```

Требуется Node 20+.

## Что внутри

Next.js 15 (App Router) + React 19 + TypeScript. Обычная страница с обычной
прокруткой: разметка, типографика и анимации появления — это React и CSS.

three.js используется в двух местах и только ради картинки:

- **первый экран** — сцена из трёх белых объектов с мягкими тенями, лёгким
  параллаксом за курсором и небольшим наездом камеры при прокрутке;
- **визуалы проектов** — пока нет реальной съёмки, карточки показывают
  студийные рендеры декораций.

Оба места вынесены в отдельные чанки и подгружаются лениво: в первую
загрузку страницы three.js не входит (≈108 kB JS против 349 kB, если бы
входил). Сцена первого экрана считает кадры, только пока видна на экране;
рендеры для галереи выполняются один раз при подходе к ней, после чего
WebGL-контекст закрывается и остаются обычные картинки.

```
src/
  app/          layout, page, globals.css — весь визуальный язык
  data/site.ts  всё содержимое: проекты, услуги, контакты
  lib/
    decor.ts        процедурные модели декораций и студийный свет
    decorStill.ts   разовый рендер визуалов для галереи
    quality.ts      профиль качества устройства
  components/   Header, Hero, Projects, About, Services, Contacts, Reveal
```

## Как менять содержимое

Тексты, проекты, услуги и контакты лежат в `src/data/site.ts` — компоненты
подстраиваются сами. Чтобы добавить проект, допишите объект в `projects`:
он встанет в нужную категорию, получит визуал и попадёт в счётчик работ.

### Заменить рендеры на реальные фотографии

Положите снимок в `public/projects/` и укажите его у проекта:

```ts
{ id: 'luna', /* … */ image: '/projects/luna.jpg' }
```

Карточка возьмёт фотографию, а рендер для этого проекта считаться не будет.
Когда фотографии появятся у всех проектов, three.js перестанет грузиться
в галерее вовсе. Пропорции кадра: 4:3, у крупных проектов (`wide: true`) —
21:9.

## Доступность и производительность

- контраст текста не ниже 4.5:1 на бетонном фоне (шаги чернил в `:root`);
- видимый фокус у всех ссылок и кнопок, порядок табуляции совпадает с
  визуальным;
- `prefers-reduced-motion` выключает параллакс, появления и наезд камеры;
- профиль качества (`lib/quality.ts`) понижает pixel ratio, тени и детализацию
  геометрии на слабых устройствах и на программном рендерере.

В разработке качество можно форсировать: `?quality=low|medium|high`.
